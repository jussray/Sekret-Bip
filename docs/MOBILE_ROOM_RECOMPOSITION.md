# Mobile Room Recomposition

Branch work for portrait, app-ready room backgrounds.

## Scope

Create non-destructive mobile variants for all four companion room families:

- Raylene
- Rylane
- Cloud
- Night

Each family receives seven phases:

- day
- midday
- afternoon
- evening
- night
- deep-night
- rain

Total: 28 mobile room backgrounds.

## Naming

`assets/images/mobile/bg-<companion>-room-<phase>-mobile.png`

Original production and archive files must remain untouched.

## Composition standard

- Portrait smartphone composition
- Clear central avatar placement area
- Calm lower 18% for bottom navigation
- Distinct tappable visual zones
- Reduced tiny decorative text and clutter
- Preserve each companion's established room identity and lighting
- No baked app buttons, navigation labels, or phone frame

## Hotspot layout

- Left: journal/pages
- Center: calm/comfort and avatar
- Right: Voice Bip
- Upper middle: Cloud Thoughts / mood surface
- Lower left: rewards/backpack when applicable
- Lower right: bed/sleep/comfort when applicable
