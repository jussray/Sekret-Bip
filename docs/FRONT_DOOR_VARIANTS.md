# Front-door variants

The public welcome screen is selected by `EXPO_PUBLIC_APP_VARIANT`.

- `teen` renders the current Se’kret Bip teen front door with Night, Suhana, Sy, Cloud, and their parents.
- `parent` renders the separate Bip Jr family front door.

Both variants keep the same Enter handoff into the existing auth/onboarding router. The teen label is canonically spelled `Suhana`; `Suhanna` is not allowed in the public welcome surface.
