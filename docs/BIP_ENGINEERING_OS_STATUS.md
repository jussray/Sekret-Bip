## Parent Bridge correction

The proposal checklist item requiring a parent to see everything exposed to a teen is rejected.

- Bridge is a consented bridge, not a surveillance window;
- private journal rows, private companion chats, raw voice/transcripts, unshared messages, general activity history, and private memory remain closed;
- a parent receives only content intentionally shared through an approved relationship-scoped contract;
- generated summaries must be authorized by an active, unrevoked share;
- visibility, revocation, blocking, deletion, and cross-user denial must be enforced in services, RPCs, RLS, storage, and route authorization;
- exact-text sharing, if ever proposed, requires a separate explicit consent, retention, revocation, and denial-tested design.
