## Evaluation contract
- Start with synthetic voice/transcription fixtures, no actual teen speech, parent/child messages, journal entries, voiceprints, or stored memories.
- Current provider routing and Cloudflare Workers voice fallback remain unchanged.
- The existing safety/preflight/moderation chain must not be weakened, skipped, or redefined by an NVIDIA skill.
- Do not add keys, proxy private data, change DNS/Workers/Service Bindings, call paid APIs, run load tests against production, or deploy unless separately approved.
- Compare transcript accuracy, end-to-end timing, quality, failure fallback, accessibility, cost, privacy, and character alignment. Use invented inputs and clear evaluation criteria.
- Evaluate adversarial cases *offline* (malformed input, injection attempts, empty clips, overlong inputs, provider timeout) and distinguish synthetic test results from live safety guarantees.
- No automatic promotion of model output to trusted character instruction, memory, or parent summary.

## Stop and handoff
Output VERIFIED / INFERRED / UNKNOWN / BLOCKED, concrete evidence, unresolved risks, approval gates, and reversible next step. Missing external governance/proof means HOLD. This skill grants **zero** model-installation, publication, production, execution, or data-sharing authority.
